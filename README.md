# Blackpine Woods

A pixel-art mushroom foraging adventure that runs in the browser. It's a single `index.html` with no build step and no dependencies beyond Google Fonts.

Start as a backpacker with 5 coins. Examine wild mushrooms (cap, underside, stem, smell) to identify them, trade with Old Wren, build a lean-to and then a cabin, grow oysters and shiitake, and explore three areas: Foxfire Cave, Willow Marsh and Highpine Ridge.

## Play

Open `index.html` in a browser, or visit the deployed site.

- **Move:** arrow keys or WASD (on-screen pad on phones)
- **Interact / continue:** E, Space or Enter
- **Basket** I · **Journal** J · **Quests** Q · **Map** M

Progress saves in the browser's local storage.

## Deploy

It's a static site, so any static host works. On Vercel, the project root is served as-is.

## Note

This is a game, not a field guide. Never eat a wild mushroom based on a description, a picture or a game. Mushroom facts are drawn from *The Mushroom Bible* by Richard Korman, rewritten for the game.
